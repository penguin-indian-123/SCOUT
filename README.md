# SCOUT

Static single-page site presenting the method, protocol, and Tables 1–3 from the SCOUT ISBI draft ("Scoring with Clinical Vocabulary and Neighbor Distance for Out-of-Distribution Detection in Medical Vision-Language Models").

## Deploy to GitHub Pages

1. Push this folder's contents to the root of a repo (or to a `docs/` folder, or a `gh-pages` branch — match whichever source you pick below).
2. In the repo: **Settings → Pages → Build and deployment → Source**, select the branch/folder containing `index.html`.
3. Save. The page publishes at `https://<username>.github.io/<repo>/` within a minute or two.

No build step — `index.html` is a single static file. The only external dependency is the Google Fonts stylesheet (Source Serif 4 + JetBrains Mono), loaded over HTTPS.
